# 📱 วิธีทำ "แอปลงทะเบียนอาหารโรงครัว" ให้เป็นแอปมือถือ (ฉบับละเอียด จับมือทำ)

ใช้ไฟล์จากชุด **canteen-app-ติดตั้งลงมือถือ-PWA.zip** (ไอคอนแอป = โลโก้น้องเชฟหน้า home)

ไฟล์ในชุด 6 ไฟล์:

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวแอป (เวอร์ชันล่าสุด ครบทุกฟีเจอร์) |
| manifest.json | ชื่อแอป + ไอคอน ที่มือถือใช้ตอนติดตั้ง |
| sw.js | ทำให้เปิดแบบออฟไลน์ได้ |
| icon-192.png / icon-512.png | ไอคอนแอป (โลโก้น้องเชฟ) |
| README-วิธีติดตั้ง.txt | สรุปย่อของคู่มือนี้ |

หลักการสั้น ๆ: **เอาไฟล์ขึ้นเว็บ (ลิงก์ https) → เปิดลิงก์บนมือถือ → กด "เพิ่มลงหน้าจอโฮม"** เท่านี้ได้แอปจริง มีไอคอน เปิดเต็มจอ ไม่ต้องผ่าน Play Store / App Store

---

## ขั้นที่ 0 — (สำคัญ ถ้าจะใช้ฐานข้อมูลจริง) ใส่ API_URL ก่อน

ถ้าจะให้ทุกเครื่อง sync ข้อมูลถึงกัน ต้องทำขั้นตอน Google Sheets + Apps Script ให้เสร็จก่อน (ตามไฟล์ "วิธีติดตั้ง-ฐานข้อมูลจริง.md") แล้ว:

1. เปิดไฟล์ **index.html** ด้วย Notepad (คลิกขวา → Open with → Notepad)
2. กด `Ctrl+F` ค้นหาคำว่า `API_URL`
3. จะเจอบรรทัด `const API_URL = '';`
4. วางลิงก์ Web App ของ Apps Script ไว้ระหว่างเครื่องหมายคำพูด เช่น
   `const API_URL = 'https://script.google.com/macros/s/XXXX/exec';`
5. กด Save แล้วปิด

> ข้ามขั้นนี้ได้ถ้าอยากทดลองก่อน (แอปจะเป็นโหมดเดโม ข้อมูลอยู่เฉพาะในเครื่อง) ใส่ทีหลังแล้วอัปโหลดซ้ำได้

## ขั้นที่ 1 — เอาไฟล์ขึ้นเว็บด้วย Netlify (ฟรี)

1. แตกไฟล์ zip → ได้โฟลเดอร์ที่มีไฟล์ 6 ตัวข้างใน (สำคัญ: ไฟล์ต้องอยู่ในโฟลเดอร์เดียวกัน ไม่ซ้อนโฟลเดอร์ย่อย)
2. เข้า **https://www.netlify.com** จากคอมพิวเตอร์ → กด **Sign up** → สมัครฟรีด้วยอีเมล (แนะนำให้สมัคร เพื่อให้ลิงก์อยู่ถาวรและอัปเดตแอปทีหลังได้ที่ลิงก์เดิม)
3. ยืนยันอีเมล แล้วล็อกอินเข้ามา จะเจอหน้า Dashboard
4. ไปที่เมนู **Sites** (หรือหน้าแรกเลย) จะมีกรอบเขียนว่า *"Want to deploy a new site without connecting to Git? Drag and drop your site output folder here"*
5. **ลากทั้งโฟลเดอร์** (ตัวโฟลเดอร์ ไม่ใช่ไฟล์ทีละตัว) ไปวางในกรอบนั้น
6. รอ 10–30 วินาที ระบบจะขึ้นว่า Deploy สำเร็จ พร้อมลิงก์ เช่น `https://sparkly-pixie-123abc.netlify.app`
7. (แนะนำ) เปลี่ยนชื่อลิงก์ให้จำง่าย: เข้าไปที่ site นั้น → **Site configuration** → **Change site name** → ตั้งเช่น `mitrlao-canteen` → ลิงก์จะกลายเป็น `https://mitrlao-canteen.netlify.app`
8. เปิดลิงก์ทดสอบบนคอมก่อน 1 รอบ ว่าแอปขึ้นหน้า home ปกติ

## ขั้นที่ 2 — ติดตั้งลงมือถือพนักงาน

ส่งลิงก์เข้ากลุ่ม LINE/WhatsApp ของบริษัท แล้วให้แต่ละคนทำตามนี้ (ทำครั้งเดียว):

**Android (ใช้ Chrome):**
1. แตะลิงก์ → เปิดใน **Chrome** (ถ้าเปิดใน LINE ให้แตะเมนู ⋮ มุมขวาบน → "เปิดในเบราว์เซอร์อื่น/Chrome")
2. รอโหลดเสร็จ ส่วนใหญ่จะมีแถบ/ป๊อปอัป **"ติดตั้งแอป"** เด้งขึ้นเอง → แตะ **ติดตั้ง**
3. ถ้าไม่เด้ง: แตะเมนู **⋮** มุมขวาบน → เลือก **"เพิ่มลงในหน้าจอหลัก"** หรือ **"ติดตั้งแอป"** → **เพิ่ม/ติดตั้ง**
4. ไอคอนน้องเชฟ 👨‍🍳 จะไปอยู่หน้าจอมือถือ

**iPhone / iPad (ต้องใช้ Safari เท่านั้น):**
1. แตะลิงก์ → ถ้าเปิดใน LINE ให้กดปุ่มแชร์แล้วเลือก "เปิดใน Safari" (หรือก็อปลิงก์ไปวางใน Safari)
2. แตะปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น □↑ ที่แถบล่าง)
3. เลื่อนเมนูลงมา แตะ **"เพิ่มลงในหน้าจอโฮม" (Add to Home Screen)**
4. แตะ **เพิ่ม (Add)** มุมขวาบน → ไอคอนน้องเชฟขึ้นหน้าจอ

เปิดจากไอคอน = เต็มจอเหมือนแอปจริง ไม่มีแถบเบราว์เซอร์ · ใครไม่สะดวกติดตั้ง เปิดผ่านลิงก์ในเบราว์เซอร์ได้เหมือนกัน

## ขั้นที่ 3 — พิมพ์ QR เช็คอินไปติดหน้าโรงอาหาร

1. เปิดแอป **จากลิงก์จริง** (ไม่ใช่ไฟล์ในเครื่อง) → เข้าเมนูผู้ดูแล (ใส่ PIN)
2. กด **"🧾 QR เช็คอินหน้าโรงอาหาร"** → QR จะชี้ไปที่ลิงก์จริงให้อัตโนมัติ
3. กด **"แชร์ / บันทึกภาพโปสเตอร์ QR"** → ได้ภาพโปสเตอร์พร้อมตารางเวลา → สั่งพิมพ์ไปติดทุกจุด

## การอัปเดตแอปในอนาคต

1. ได้ไฟล์ index.html เวอร์ชันใหม่มา → ใส่ API_URL เดิม (ถ้ามี) → วางทับในโฟลเดอร์เดิม
2. เข้า Netlify → เลือก site → แท็บ **Deploys** → ลากโฟลเดอร์วางในหน้านั้นอีกครั้ง
3. ลิงก์เดิม ไอคอนที่พนักงานติดตั้งไว้เดิม ใช้ต่อได้ทันที ไม่ต้องติดตั้งใหม่ (เปิดแอปครั้งถัดไปจะได้เวอร์ชันใหม่เอง)

## ปัญหาที่เจอบ่อย

- **ไม่มีปุ่ม "ติดตั้งแอป" บน Android** → ใช้เมนู ⋮ → "เพิ่มลงในหน้าจอหลัก" แทน ได้ผลเหมือนกัน
- **iPhone หาปุ่ม "เพิ่มลงหน้าจอโฮม" ไม่เจอ** → ต้องเปิดด้วย Safari เท่านั้น (Chrome บน iPhone ก็ไม่ได้)
- **เปิดจาก LINE แล้วติดตั้งไม่ได้** → LINE เปิดเว็บในตัวเอง ต้องกดเปิดใน Chrome/Safari ก่อน
- **แก้เมนู/ข้อมูลแล้วอีกเครื่องไม่เห็น** → ยังไม่ได้ใส่ API_URL (ขั้นที่ 0) หรือเครื่องนั้นยังเปิดเวอร์ชันเก่าค้าง ให้ปิดแอปแล้วเปิดใหม่
